# Web

The browser app where people read and write logbooks.

## Language

**Entry**:
An item in a logbook. It stands alone, comments on another entry, or quotes one.
_Avoid_: paragraph, snippet, post

**Entry content**:
The formatted text of an entry together with the files it refers to. The two belong together.
_Avoid_: editor data, notification message, snippet content, textcontent
